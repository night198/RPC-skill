# 开发进度、交接与会话台账

持久状态是长程开发的恢复依据。每个项目/批次在项目外的私有目录保存；沿用项目已有规范，不维护多份重复的状态。项目需要跟踪的非敏感进度可放仓库，但原生 sessions、进程信息与私有证据不要进入公开仓库或公共同步盘。

建议目录：

```text
<private-project-batch>/
  开发进度.md       # 每片状态与主控验收事实
  进度交接.md       # 当前有效现场与精确下一步
  会话台账.md       # RPC 身份、配置、归属与操作回执
  sessions/         # 原生会话，由 OMP 写入
  evidence/         # 脱敏验证证据
```

三份文档各司其职，以切片 id 和证据路径互相引用。进度不复制 transcript，交接不重复完整验收历史。已有一份统一文档时可以用对应章节，不强制拆出三个文件。

## 开发进度模板

```markdown
# 开发进度
项目：<绝对路径>
目标与验收：<有效 Spec 路径/版本>
更新时间：<时间及时区>

| 切片 id | 行为/Spec 段落 | 依赖 | 状态 | 文件所有权 | 请求 id | 主控验收证据 | 下一动作 |
|---|---|---|---|---|---|---|---|
| <id> | <单一行为> | <id 或无> | <状态> | <会话/文件> | <RPC id 或未派发> | <路径或未验收> | <具体动作> |

## 当前阻塞
<原因、已核对内容、需要谁作何决定；没有则写无>
## 未验证项
<开发会话报告但主控未确认的结论；没有则写无>
```

状态：待派发 → 执行中 → 待主控验收 → 通过 / 待修正。错误、取消单独记录；失联/超时记为结果未知，不能自动退回未执行。通过才推进依赖片。保留失败和修正证据，不覆盖成“从未失败”。

更新顺序：派发前记执行中和 request id → 回合 settled 后记结果/待验收 → 主控核验后记通过或待修正 → 更新交接下一片 → 才派发依赖片。

## 进度交接模板

```markdown
# 进度交接
检查点：<时间/当前切片>
有效目标与 Spec：<路径/版本/段落>
授权：<允许文件、命令、测试资源>
禁止：<提交/推送/部署未授权，以及其他限制>

## 已完成
<引用开发进度的通过片及主控证据，不复制全部日志>
## 当前现场
- 用户已有修改：<具体文件/内容，或无>
- 未完成编辑：<文件/符号/实际状态，或无>
- 文件所有权：<当前写入者及范围>
- 最后请求：<id、completed/error/aborted/结果未知，settled 证据>
- 仍在运行的资源：<归属、用途、处置要求，或无>
- 未验证与阻塞：<具体内容，或无>

## 下一片
- id/目标：<一个行为>
- 输入输出、字段、错误和副作用顺序：<精确契约>
- 允许文件/符号、调用方、禁改范围：<具体列表>
- 验收场景与允许命令：<精确步骤>
- 输出及停止点：<证据要求；完成即停>

## 恢复核对
<需读取的源码、实际工作树状态、原生 sessionFile 引用、模式/窗口与占用要求>
```

压缩、换会话和计划停止前先更新交接。新会话先核对现场，再按下一片执行。文档和源码冲突时先查清并修订；摘要不能扩大授权，也不能证明写操作应重放。

## 会话台账模板

```markdown
# 会话台账
项目/批次：<绝对路径及批次名>
OMP：<实际可执行文件和版本>
Profile：<明确值/默认环境；无秘密>
sessionId：<运行返回值>
sessionFile：<运行返回的精确绝对路径>
控制端：<唯一主控身份、是否持有 stdin>
进程归属：<PID、启动时间、可执行文件、命令行的非秘密部分>
启动约束：<参数及附加边界，不含凭据>
配置证据：<模型、thinking、Fast enabled/active、窗口、extended-context、作用范围>
工具/扩展：<实际 dumpTools 和授权范围>
当前请求：<id、切片、真实状态、settled/队列>
最近上下文：<实际 percent、检查时间及窗口证据>
上下文操作：<shake/compact 请求 id、结果、操作前后占用>
现场/验收：<引用交接与进度>
中断：<原因、可能副作用、恢复前需核对内容>
```

不得保存凭据、完整 models 配置、生产连接串或可复用令牌。开发输出、会话和截图也可能含私有数据，按当前用户权限保存。

## 用户看到的进度

主控简报只报：当前片、实际完成和验收、阻塞、下一动作、是否压缩/换会话。独立开发会话保留历史有助于审查、复盘和恢复；持久会话不等于进程永远运行。主控退出后本方法不保证自主推进。
